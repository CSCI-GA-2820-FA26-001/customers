## Overview

The Customers service provides a REST API for creating, listing, reading,
updating, and deleting customer records.

It is built with Python, Flask, and SQLAlchemy, and uses PostgreSQL
in the development container.

## Development Setup

### Prerequisites

- Git
- Docker Desktop, installed and running
- Visual Studio Code with the Dev Containers extension

### Open the project

1. Clone the repository:

   ```bash
   git clone https://github.com/CSCI-GA-2820-FA26-001/customers.git
   cd customers
   ```

2. Open the `customers` folder in Visual Studio Code.

3. Open the Command Palette and select:

   ```text
   Dev Containers: Reopen in Container
   ```

4. Wait for the container setup to finish.

5. Open a terminal inside VS Code. The project directory inside the
   container is `/app`.

6. Install the project dependencies:

   ```bash
   make install
   ```

The development container configuration starts the application environment
and a PostgreSQL database, and forwards port 8080.

## Run the Service

Run the following command in the development container terminal:

```bash
make run
```

The service is available at:

```text
http://localhost:8080
```

Check the service information:

```bash
curl -i http://localhost:8080/
```

Expected response body:

```json
{
  "name": "Customers Service"
}
```

Press `Ctrl+C` in the service terminal to stop it.

## Run Tests and Code Checks

Run the automated tests:

```bash
make test
```

The required minimum test coverage is 95%.

Run the code style and quality checks:

```bash
make lint
```

Tests create and delete database records. Run them in the development
environment, using a database that contains no important customer data.

## Customer Fields

| Field | Type | Description |
| --- | --- | --- |
| `id` | integer | Generated by the service when a customer is created |
| `first_name` | string | Required, non-empty first name |
| `last_name` | string | Required, non-empty last name |
| `email` | string | Required, non-empty email value |
| `address` | string or null | Optional; defaults to null |
| `active` | boolean | Optional; defaults to true |

POST and PUT requests must use `Content-Type: application/json`.
Both require `first_name`, `last_name`, and `email`.

For PUT requests, omitted optional fields are reset to their defaults:
`address` becomes null and `active` becomes true.

## API Endpoints

| Method | Endpoint | Description | Success status |
| --- | --- | --- | --- |
| GET | `/` | Get service information | 200 OK |
| POST | `/customers` | Create a customer | 201 Created |
| GET | `/customers` | List all customers | 200 OK |
| GET | `/customers/<id>` | Read a customer | 200 OK |
| PUT | `/customers/<id>` | Update a customer | 200 OK |
| DELETE | `/customers/<id>` | Delete a customer | 204 No Content |

Reading, updating, or deleting a customer that does not exist returns
404 Not Found.

Invalid customer data returns 400 Bad Request.
POST or PUT requests with an unsupported content type return
415 Unsupported Media Type.

## API Examples

Keep the service running, and use a second terminal to execute these commands.

### Create a customer

```bash
curl -i -X POST http://localhost:8080/customers \
  -H "Content-Type: application/json" \
  -d '{
    "first_name": "Ada",
    "last_name": "Lovelace",
    "email": "ada@example.com",
    "address": "123 Example Street",
    "active": true
  }'
```

The response returns the created customer, including its generated `id`.
The `Location` response header contains the URL of the new customer.

For the remaining examples, replace `123` below with the actual `id`
returned by the POST request:

```bash
CUSTOMER_ID=123
```

Run the remaining commands in the same terminal so that this variable
remains available.

### List all customers

```bash
curl -i http://localhost:8080/customers
```

Returns a JSON array. If there are no customers, the array is empty: `[]`.

### Read a customer

```bash
curl -i "http://localhost:8080/customers/$CUSTOMER_ID"
```

### Update a customer

```bash
curl -i -X PUT "http://localhost:8080/customers/$CUSTOMER_ID" \
  -H "Content-Type: application/json" \
  -d '{
    "first_name": "Ada",
    "last_name": "Lovelace",
    "email": "ada.updated@example.com",
    "address": "456 Example Avenue",
    "active": false
  }'
```

Returns the updated customer.

### Delete a customer

```bash
curl -i -X DELETE "http://localhost:8080/customers/$CUSTOMER_ID"
```

A successful deletion returns 204 No Content with an empty response body.

Reading or deleting the same customer afterward returns 404 Not Found.

## Project Structure

| Path | Purpose |
| --- | --- |
| `.devcontainer/` | Development container and PostgreSQL configuration |
| `service/models.py` | Customer model, validation, and database operations |
| `service/routes.py` | REST API endpoints |
| `service/config.py` | Application configuration |
| `service/common/` | Shared status codes, logging, error handlers, and CLI commands |
| `tests/` | Automated tests and test data factories |
| `Pipfile` | Python dependencies managed with Pipenv |
| `Pipfile.lock` | Locked dependency versions |
| `Makefile` | Commands for installation, running, testing, and linting |
| `Procfile` | Service startup command |
| `wsgi.py` | Application entry point |
